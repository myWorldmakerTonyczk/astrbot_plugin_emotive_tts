# 已确认的试听结论

日期：2026-11-02。以下为用户试听选择，不是由音频时长推断的主观评分。

1. 单纯提高语速能减轻慢吞吞的机械感，但不等于改善情感。
2. 新音色下，“具体语气转折指令 + 1.12倍语速”比单纯提速略好。
3. 三段后续台词中，用户选择 B：整段合成，描述该段的情绪走向，语速1.12。
4. 分句合成再拼接（D）不作为默认；逐字音高、毫秒停顿、长篇表演说明不作为首版方向。

采用模板：用普通话，先心虚地解释，再着急阻止，最后小声懊恼，别尖叫。
模板只说明风格，不应每句话固定使用这些情绪。分析模型须根据上下文和正文重新生成，普通聊天允许单一、平静语气。

`context_messages=5` 指本次用户输入之前最近5条 user/assistant 历史消息，不是5轮。当前输入、当前回复和有限角色背景另传；仅使用当前AstrBot请求已有的历史。

实验使用 cosyvoice-v3.5-plus；模型和音色能力不同，结论不能保证迁移到任意音色仍然成立。每个条件只有一次样本，未固定随机种子。
