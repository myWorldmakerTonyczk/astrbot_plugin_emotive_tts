# 上下文情绪语音 · Emotive TTS

AstrBot 语音插件：结合近期对话、语音人设与本句正文，先让 LLM 生成简短的语气指令，再使用阿里云语音模型合成整段语音。

## 功能

- 按概率将机器人回复转为语音，支持私聊/群聊开关和独立 UMO 白名单。
- 提供自动分析语气、手动指定 instruction 的两个 LLM 工具。
- 配置语音人设、上下文条数、语速和固定种子。
- 支持阿里直连、兼容接口，或复用平台已配置的阿里 dashscope_tts 连接配置。
- 语气分析可选择平台已配置的聊天模型，或独立的兼容分析 API。
- 种子试听：五种固定语境，随机比较 2～4 个种子，或手动输入 1～4 个。音频保留到手动删除，确认后才用于正式语音。
- 生成或发送失败时保留文字；工具发送成功后补充语音正文记忆。

## 安装

要求 AstrBot >= 4.29.3、Python >= 3.12，当前面向 OneBot v11（NapCat / SnowLuma）。

在 AstrBot 插件管理中使用本仓库地址安装：

```text
https://github.com/myWorldmakerTonyczk/astrbot_plugin_emotive_tts
```

也可通过插件管理的“从文件安装”导入安装包。重载插件后，在插件详情打开 **语音设置** 视图；全部设置均在视图中管理。

## 配置步骤

1. **连接与音色**：选择语音 API，填写对应凭据、模型及匹配的音色。使用平台模式时，选择已配置的阿里 dashscope_tts 提供商；合成仍由本插件执行，动态 instruction 和视图语速继续生效。
2. **语气与上下文**：选择语气分析用的聊天模型，填写语音人设。平台模式必须明确选择提供商，不自动跟随当前会话；未配置或分析失败会回退到默认指令。
3. **发送与会话**：设置自动转换概率与可用会话。UMO 通过 `/sid` 获取；白名单留空表示不限制该类会话。
4. **种子试听**：先保存设置，再随机生成或输入种子，例如 `37, 1286, 52803`。切换开心、低落、安慰、俏皮、心虚语境，比较候选 A/B/C，再确认喜欢的种子。

建议先使用支持自然语言 instruction 的 CosyVoice 模型及匹配音色。实际效果受音色、模型、语气判断及种子影响，不保证每次生成的表现一致。

## 参数与行为

- 默认最近 **5条消息**，不是5轮；当前用户输入与本句正文另传。0表示不提供历史消息。
- 默认语速 **1.12**；手动工具可为单次调用指定语速。
- 默认种子 **-1**：不主动传 seed；指定种子范围为 **0～65535**，数值大小不代表质量。
- 最终 instruction 上限为100加权字符（ASCII算1，其他字符算2）；超长、无效返回或超时会回退默认指令。
- 自动转换关闭后，LLM 仍可使用语音工具；工具成功发送后，本轮最终回复不会再次自动转语音。
- 自动转换跳过已包含语音及流式完成结果；如要自动朗读完整回复，请关闭对应会话的流式输出。

### LLM 工具

- `emotive_send_voice_auto`：输入正文与可选上下文数量，按配置的语音人设、分析模型及语速生成语音。
- `emotive_send_voice_manual`：输入正文、简短 instruction 及可选语速，跳过额外语气分析。

语音成功发送后记录正文，不将音频或 instruction 存入普通对话历史。对于第三方插件另行管理历史的情况，插件提供按会话隔离的补充记忆；详见源码与变更记录。

## 用量与数据

普通自动语音通常需要一次语气分析和一次语音合成。试听每种语境只分析一次，所有候选共用该指令，默认3个种子共15份音频；会使用你配置的 API 额度。

分析服务会收到限定的上下文、当前输入、正文、语音人设和可选聊天角色背景。高级设置中的 **临时打印语气分析日志** 默认开启，包含这些聊天文本和最终 instruction；调试结束后可关闭。连接凭据不会主动写入调试日志。

试听文件、配置快照与成功语音正文补充记忆均存于 AstrBot 插件数据目录，仓库不包含实际凭据、会话数据库或生成音频。试听不发送聊天、不写入会话记忆；确认种子不会删除对比。重载中断的试听不会自动续跑。

## 开发

```bash
python -m pip install -r requirements-dev.txt
python -X utf8 -m pytest -q
python -m ruff check src tests
node tests/settings_ui.cjs .
node tests/seed_ui.cjs .
```

框架入口为 `main.py`，业务源码位于 `src/`，配置视图位于 `views/settings/`。更多说明见 [开发说明](docs/DEVELOPMENT.md) 与 [变更记录](CHANGELOG.md)。
